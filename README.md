## AI衣橱

上传自己的衣服、裤子和鞋子照片，AI 识别建档；确认单品后，输入温度和场合，生成来自自己衣柜的穿搭方案与理由，缺少合适单品时给出缺件提示。

**[👉 点击体验 AI衣橱](https://53d43a3c36282c.app.lhr.life/)**

使用步骤：上传照片 → 确认或修改识别结果 → 打开“今天怎么穿” → 输入温度和场合 → 生成搭配。

> 当前为公开测试版，使用临时链接，运行电脑需要保持开机联网。地址可能轮换或失效；每个浏览器的衣柜独立保存，不支持跨设备同步。测试版全站每日识别上限 20 张、生成上限 30 次。
