# 隐私说明（当前设备版）

设备首次使用时生成匿名UUID，用于区分该设备的衣柜、搭配与会话；当前Web版本保存在本机localStorage，不创建账号。重新安装或清除本机存储可能失去原设备归属。

衣物照片保存在服务端本地uploads目录，识别时发送至已配置的多模态模型API处理，不上传第三方文件存储。识别属性、用户修改、来源和校正记录用于生成与校验搭配。

使用“清空我的数据”接口会删除该设备的衣柜、搭配、方案关联、会话和上传照片；其他设备的数据不受影响。为防止通过清空绕过每日限制，当日使用额度计数暂时保留：计数仅关联设备ID与服务端盐计算的SHA256，不存原始设备UUID、照片或衣柜内容。

**使用额度记录保留至次日 0 点，不含照片与衣柜内容。** 日界采用北京时间；服务运行时在午夜清理，停机后再次启动先清理已过期计数，过期额度不计入新一天。

本说明对应T13当前实现，不代表已部署或已完成应用商店审核。人工测试报告与基准素材属于开发验收资料，不属于用户衣柜。

## 身材资料补充（2026-11-18）

可选填写身高（cm）、体重（kg）和五种体型之一，来源均为用户输入，按设备隔离存于本机数据库。可修改或清空；清空设备数据也删除资料。填写后生成搭配时，这三项会随候选衣物发送给既有模型服务，用于推荐说明，不用于硬过滤、尺码测量或合身保证；不记入模型调用日志，不新增账号/跨设备同步。未填写不影响基础搭配。

### 城市天气（T19）
由你搜索并选择城市；后端仅把查询词或所选经纬度发送给Open-Meteo，获取七天预报，不发送设备UUID、衣柜、人像或身材资料。不请求GPS；所选城市仅在当前页面会话中保留，刷新后重新选择。天气数据来源标注Open-Meteo，失败时可手动输入温度。

### 应用内社区（T20，2026-11-19）

私人衣柜默认不公开。仅在你主动点击发布后，所选照片（或所选衣物照片的独立副本）、标题、正文及你发表的评论对其他使用者可见。公开作者使用独立随机代号与生成昵称，不公开设备UUID、私有单品ID、文件路径或身材资料。点赞、关注、投票用于显示真实互动；每设备每帖一票。

删除衣柜单品不会撤回已发布照片副本；删除帖子会移除该帖、公开图片及相关互动。清空设备数据还会撤回该设备全部帖子、作者与互动，其他设备发布的内容保留，当日匿名额度仍按原规则保留至次日0点。文件系统清理失败时会明确提示并允许重试。

社区沿用设备身份，不提供账号登录或身份找回；清除浏览器存储可能失去管理已发内容的能力。本轮社区验收在隔离临时库中完成，没有将测试帖子灌入用户衣柜或默认社区。


### 试穿体验（T21，2026-11-19）

服饰体验目录仅接收操作者明确说明来源与使用权的素材，暂不表示任何平台合作，私人衣柜不会自动发布到目录。试穿需主动选择本人或获许可的人物照片并确认处理说明；身高/体重/体型不能代替该照片。

默认由后端将人物图和服饰图直接发送给FASHN处理，不创建公开人物图片URL或上传第三方对象存储。输入仍会由服务临时处理；其官方政策说明base64结果可获取60分钟、请求元数据不会自动删除，本地清空不能保证供应商记录同步删除。详见https://docs.fashn.ai/api-overview/data-retention-privacy 。本轮没有向FASHN发送真实照片或生成请求。

人物照片、试穿结果与任务保存在服务端本地，按设备隔离，未经主动另行发布不进入社区。可删除试穿任务或清空设备数据；后者删除该设备任务和照片，不删除他人数据或共享体验目录，也不代表远端在途任务取消。

防重复生成的当日匿名请求摘要与试穿次数保留至北京时间次日0点，不含原设备UUID、人像、结果或商品内容；旧提交凭据短期到期且不过午夜，删除记录后旧请求不会重新生成或恢复照片。额外的本机迁移备份属于操作者控制的开发备份，不属于清空API的在线数据范围；本轮未将备份上传GitHub。
